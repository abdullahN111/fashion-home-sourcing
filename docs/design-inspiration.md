# Design Critique & Upgrade Strategy

## Weaknesses of Reference Site to Fix
1. Visual Hierarchy: Current hero section text is cut off (`Responsibly Building a Susta_`) and lacks contrast against busy background images.
2. Iconography: Uses inconsistent, dated 3D clip-art graphics inside Core Values. Replace entirely with modern minimalist SVGs from `lucide-react` (e.g., `ShieldCheck`, `Layers`, `Globe2`, `Cpu`).
3. Card Design: Current value cards use thick, uneven brown outlines. Replace with sleek, elevated white cards on a faint off-white background with subtle border highlights.
4. Navigation Clutter: Header and footer are overloaded with miscellaneous subcategories. Streamline into 4 core links.
5. Typography & Density: Fix microscopic, bulleted product text; replace with structured feature grids and spec badges (e.g., `T-120 to T-1200`, `200–1000 GSM`, `100% Combed Cotton`).

## Target Look & Feel
- Sleek modern manufacturing company (similar to Apple or Stripe design polish applied to industrial textiles).
- Crisp hero section with clear typography, bold value propositions, and dual action buttons: `Explore Products` and `Request a Quote`.
